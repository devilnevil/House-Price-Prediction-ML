# 🏡 House Price Prediction using Machine Learning

## 📌 Project Overview
This project predicts house prices based on various features such as sqft_living, bedrooms, bathrooms, and location using Machine Learning algorithms.

## 📊 Dataset Information
- **Source**: House Sales in King County, USA (or mention your dataset name)
- **Rows**: 4600
- **Columns**: 18 features (price, bedrooms, bathrooms, sqft_living, etc.)

## 🛠️ Tech Stack & Libraries
- **Language**: Python
- **Libraries**: NumPy, Pandas, Matplotlib, Seaborn, Scikit-learn

## 🚀 Workflow
1. **Data Preprocessing**: Handled missing values, explored features.
2. **Exploratory Data Analysis (EDA)**: Visualized price distributions and correlations.
3. **Model Training**: Linear Regression / Random Forest (whichever you used).
4. **Evaluation**: Evaluated using MAE, MSE, and R² Score.

## 📈 Key Insights
- Feature `sqft_living` had the highest positive correlation with house prices.
